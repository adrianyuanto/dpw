Apa itu AJAX?

AJAX (Asynchronous JavaScript and XML) merupakan teknik pengembangan web yang memungkinkan halaman web terhubung dengan server dan memperbarui data tanpa perlu me-reload seluruh halaman.

Apa itu jQuery?

jQuery adalah library JavaScript yang dibuat untuk menyederhanakan DOM (HTML), event handling, animasi, dan pemanggilan AJAX.
