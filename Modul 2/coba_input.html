Uji coba 2



Kesimpulan uji coba 2:
Ketika atribut name tidak diberikan, semua tombol bisa dipilih secara bersamaan karena browser tidak mengelompokkannya dalam satu grup. Ketika atribut name diisi dengan nilai yang sama untuk semua tombol, hanya satu pilihan yang bisa dipilih pada satu waktu karena browser menganggap mereka satu grup. Ketika atribut name diisi dengan nilai yang berbeda untuk setiap tombol, semua tombol kembali bisa dipilih secara bersamaan karena mereka dianggap grup yang berbeda-beda.

Uji coba 3



Kesimpulan uji coba 3:
Berbeda dengan tombol sebelumnya, checkbox memperbolehkan pengguna memilih lebih dari satu pilihan sekaligus, tidak peduli apakah atribut name sama atau berbeda. Atribut name pada checkbox berfungsi sebagai penanda ketika data dikirim ke server, bukan untuk membatasi pilihan.

Uji coba 4




Kesimpulan uji coba 4:
Input type color menampilkan color picker sehingga pengguna dapat memilih warna dengan mudah. Input type date menampilkan kalender untuk memilih tanggal. Input type button menampilkan tombol yang bisa dihubungkan dengan fungsi JavaScript melalui atribut onclick.

Uji coba 5




Kesimpulan uji coba 5:
Input type datetime-local memungkinkan pemilihan tanggal sekaligus jam. Input type month menampilkan picker untuk memilih bulan dan tahun. Input type email memvalidasi format email secara otomatis pada browser modern sehingga pengguna tidak bisa mengirim form jika format email salah. Tampilan masing-masing input bisa berbeda di setiap browser.

Uji coba 6




Kesimpulan uji coba 6:
Input type image menampilkan gambar yang berfungsi sebagai tombol submit. Input type file menampilkan tombol untuk memilih file dari perangkat pengguna. Input type hidden tidak terlihat di halaman, namun nilainya tetap dikirim ke server bersama data form.

Uji coba 7



Kesimpulan uji coba 7:
Input type number membatasi input hanya berupa angka dan mendukung atribut min dan max. Ketika nilai min diubah menjadi -50, slider atau input number bisa menerima nilai negatif hingga -50. Input type range menampilkan slider, cocok digunakan untuk nilai dalam rentang tertentu namun nilai aktual tidak langsung terlihat tanpa bantuan JavaScript.

Uji coba 8




Kesimpulan uji coba 8:
Input type url memvalidasi format URL (harus diawali http:// atau https://). Input type search mirip dengan type text namun memiliki tampilan khusus di beberapa browser (ada tombol X untuk menghapus teks). Input type tel tidak memvalidasi format otomatis, namun atribut pattern dapat digunakan untuk menentukan format yang diizinkan.

Uji coba 9



Kesimpulan uji coba 9:
Input type waktu memungkinkan pemilihan jam dan menit. Input type week memungkinkan pemilihan minggu dalam setahun. Dukungan kedua tipe ini bervariasi antar browser input type week secara native.
