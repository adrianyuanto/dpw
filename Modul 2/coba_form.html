Jika Anda mengklik tombol "Kirim", data formulir akan dikirim ke halaman "/action_page.php".

Kesimpulan Uji Coba Form: 1. Tombol Reset menghapus input dan mengembalikan nilai ke "Adrian" dan "Yuanto".
2. Tombol Kirim mengarahkan data ke link di `action`.
3. Atribut `target="_blank"` membuat form terbuka di tab baru saat dikirim.
4. Jika menggunakan `method="get"`, data input akan terlihat menyambung pada URL, sedangkan `method="post"` akan menyembunyikan data di URL dan mengirimnya melalui badan (body) HTTP.
